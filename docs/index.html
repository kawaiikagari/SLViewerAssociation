SLViewerAssociation

Second Lifeのリンク（secondlife://）を、好きなビューアーから選んで開くWindows用ユーティリティ

📥 最新版のダウンロード

以下のボタンからインストーラーをダウンロードできます。

インストーラーをダウンロード (EXE)
GitHubリポジトリを見る

✨ 主な特徴

  • 自動検出: 公式ビューアー、Firestorm、Alchemyなどを自動で探してリスト化します。
  • 起動モード切替: 毎回ポップアップから選ぶか、前回選んだビューアーを常に使うかを自由に選択可能。
  • クリーン設計: 常駐なし・管理者権限不要で、ユーザー環境に安全にセットアップされます。

🚀 導入手順

  1. 上のボタンから SLViewerAssociation_Setup.exe をダウンロードします。
  2. ファイルをダブルクリックして実行すると、自動でセットアップが行われツールが起動します。
  3. 一覧から使用するビューアーを確認し、設定を適用してください。

🛠️ システム要件

  • 対応OS: Windows 10 / 11 (64bit)
  • ランタイム: .NET デスクトップ ランタイム (必要に応じて自動適用)
