# SLViewerAssociation

Second Lifeのリンクを、登録したビューアーから選んで開くWindows用ツールです。

公式ビューアー、Firestorm、Alchemyなどを自動検索し、名前付きの一覧として保存します。**毎回選ぶ**か、**前回選んだビューアーを使う**かを自分で変更できます。地域や座標などのURLは固定しません。

## はじめに

1. 配布ZIPを展開し、フォルダーを使い続ける場所に置きます。
2. `SLViewerAssociation.exe` をダブルクリックします。
3. 初回はビューアーを自動検索します。追加で探す場合は **自動で探す** を押します。
4. 一覧にないビューアーは **手動で登録** から `.exe` を指定します。
5. **毎回ビューアーを選ぶ**、または **前回選んだビューアーを使う** を選び、**選んだ設定を適用** を押します。

以後、Second Lifeのリンクを開くと設定が使われます。HTTPSの地図ページでは **Teleport** を押してください。

毎回選ぶ画面では、**次回もこのビューアーを使う** にチェックを入れると次回の選択を省略できます。設定画面から「毎回選ぶ」に戻すこともできます。

詳しくは [取扱説明書](取扱説明書.md) を参照してください。

## 主な機能

- インストール情報・標準フォルダー・起動中のプロセスからのビューアー自動検索
- ビューアーの名前付き登録、編集、一覧からの削除
- 毎回選択／前回の選択を使用、の切り替え
- 同じ実行ファイルの重複登録防止
- 起動先が見つからない場合の選択画面への切り替え
- 設定前のユーザー関連付けへの復元

自動検索の対象には、公式ビューアー、Firestorm、Alchemy、Black Dragon、Cool VL Viewer、Singularityなどが含まれます。独自の配置・製品名・ポータブル版は手動登録も利用できます。

## 動作環境と配布

- Windows 10 / 11
- .NET Framework 4.8
- `--url` 引数に対応したSecond Lifeビューアー

利用者にコンパイラーは不要です。管理者権限・常駐・ブラウザー拡張・ネットからの自動ダウンロードも不要です。

**現在の配布exeは未署名です。WindowsのSmartScreenやSmart App Controlなどが警告・ブロックする可能性があります。警告が出ないことを保証するものではありません。** セキュリティ機能を無効にすることを利用条件にはしていません。

設定内容と動作の範囲は [SECURITY.md](SECURITY.md) を参照してください。

## ファイル構成

- `SLViewerAssociation.exe`：設定画面とリンク受付・選択画面
- `SLViewerAssociation.exe.config`：実行設定
- `取扱説明書.md`・`使い方.txt`：操作方法
- `source/`：C#ソース、ビルドスクリプト、テスト
- `CHANGELOG.md`：変更履歴
- `SECURITY.md`：保存先、変更範囲、署名について
- `LICENSE`：GNU GPL v3の全文

## ソースからのビルド

C# / Windows Formsで実装しています。設定ツールを終了してから、リポジトリ直下で実行します。

```powershell
.\source\build.ps1
```

Windowsの .NET Framework 付属C#コンパイラーを使用します。

テストを実行する場合：

```powershell
.\source\tests\run.ps1
```

テストは一時フォルダーとテスト用ビューアーを使用します。Windowsの関連付け変更や、実際のSecond Lifeビューアーの起動は行いません。
